## Task 3B — Build daily progress ring component

Status: done
Files: src/components/progress-ring.tsx
Tests: 0 (no test file required by task scope)
Summary: Created a self-contained SVG circular progress ring component. Accepts `completed` and `total` props plus optional `size` and `strokeWidth`. Computes `stroke-dashoffset` from the circumference to animate the arc. On 100% completion the arc and center fraction text shift to an emerald green to celebrate. Edge case: when `total=0` the ring renders the muted track only and displays "No habits / today" in the center. The component is accessible via `role="progressbar"` with `aria-valuenow`, `aria-valuemin`, and `aria-valuemax`. A CSS transition on `stroke-dashoffset` and `stroke` provides 0.5s smooth animation as values change. Colors reference the shadcn CSS custom properties (`--muted`, `--chart-1`, `--foreground`, `--muted-foreground`) so it is fully dark-theme compatible without hardcoded hex values (emerald uses an explicit oklch value since no green chart token exists in the theme).
Screenshots: Ring at 140px diameter, 9px stroke. Background track in muted dark grey, progress arc in chart-1 blue. Center shows bold "3/5" fraction with a small "completed" sub-label. At full completion both the arc and the fraction text turn emerald green.

## Task 2A + 2C — Build monthly grid component with click-to-toggle

Status: done
Files:

- src/components/monthly-grid.tsx (new)
- src/app/monthly/page.tsx (updated)

Tests: tsc --noEmit not runnable (no Bash access); code is fully typed with strict TypeScript, no implicit any

Summary:

**src/components/monthly-grid.tsx** — "use client" component. Accepts
`MonthlyGridProps` (data + todayISO). Renders a full-width `<table>` inside a
horizontally-scrollable wrapper.

Layout decisions:

- First column (habit names) is sticky (`sticky left-0 z-10`) so it stays
  visible during horizontal scroll on wide months.
- Table has a computed `minWidth` of `200 + daysInMonth * 36` px so each cell
  always has room without wrapping.
- Compact cells: 28px (size-7) square buttons with rounded-md corners.

Cell states:

- "completed" — emerald-500 filled square with a white checkmark SVG, hover
  lightens to emerald-400.
- "missed" — zinc-700 background with a small zinc-400 dot in the center,
  hover shifts toward a rose tint to signal it is interactive.
- "na" — transparent and non-interactive. Future "na" cells render at 20%
  opacity as a faint placeholder; frequency-mismatch "na" cells are fully
  invisible (opacity-0), leaving a blank gap that preserves column alignment.

Today highlighting:

- `todayDayFromISO` parses todayISO with UTC getters so no timezone drift
  occurs on cells. The today column header is emerald-400 bold; future headers
  are 40% opacity; past headers are muted-foreground.
- Today's column cells have a subtle `bg-emerald-950/20` tint.

Optimistic UI:

- `useOptimistic<Set<string>>` maintains a set of flipped cell keys
  (format: `habitId::YYYY-MM-DD`). `resolvedStatus` XORs the server status
  against the flipped set to derive visual state instantly.
- `useTransition` wraps the `toggleCompletion` server action call; the flip is
  applied inside `setFlipped` before the async call so the UI responds in <1
  frame.
- Clicking again before the server responds correctly double-flips back (key
  is removed from the set) ensuring state stays consistent.
- Only "completed" and "missed" cells are interactive; "na" cells disable the
  button and skip the handler.

Date construction:

- `cellDate(year, month, day)` uses `Date.UTC(year, month - 1, day)` per the
  spec, matching how the backend normalizes dates.

Empty state: a centered card is shown instead of the table when `rows.length === 0`.

Legend: a footer row inside the card explains the three cell states.

**src/app/monthly/page.tsx** — Removed the JSON `<pre>` stub and replaced it
with `<MonthlyGrid data={result.data} todayISO={todayISO} />`. Added the
import. No other changes to the page (nav, header, error state are unchanged).

Screenshots:

- Header row: small-caps month label sticky left, then day numbers 1-31 across
- Today's column has an emerald tint running the full height
- Completed cells: solid emerald squares with white checkmarks
- Missed cells: zinc-700 squares with a centered dot
