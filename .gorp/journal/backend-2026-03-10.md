Summary:
Implemented three new server actions in src/actions/completions.ts:

1. `getMonthlyGridData(year, month)` -> `ActionResult<MonthlyGridData>`
   - Fetches active habits and month completions in parallel (Promise.all)
   - Builds O(1) Set keyed as "habitId|YYYY-MM-DD"
   - Iterates each day 1..daysInMonth; marks future days and non-applicable days as "na"
   - Returns { year, month, daysInMonth, rows }

2. `getOverallStreaks()` -> `ActionResult<OverallStreaks>`
   - Fetches all active habits, calls existing getStreaks() for each in parallel
   - Finds max currentStreak (with bestHabitName) and max longestStreak across all habits
   - Returns null bestHabitName when no habits exist

3. `getDashboardStats(days = 30)` -> `ActionResult<DashboardStats>`
   - Single findMany for habits, single findMany for completions in the window
   - Builds completionSet once; all computation done in-process
   - Computes trend (TrendPoint per day), weeklyRate (last 7 days), monthlyRate (full window)
   - Builds sparklines per habit with inline currentStreak (bounded to the window)
   - Rates stored as values 0..1 (rounded to 2 decimal places)

Type import pattern follows existing habits.ts convention: `habit.frequency as unknown as FrequencyConfig`
