Summary:
Fixed all TypeScript errors from the Tamagui v5 config switch (onlyAllowShorthands: true).

The actual v5 shorthand set (from @tamagui/shorthands/v4) is smaller than documented
in the task brief. Valid shorthands are:
  bg=backgroundColor, text=textAlign, items=alignItems, justify=justifyContent,
  self=alignSelf, content=alignContent, grow=flexGrow, shrink=flexShrink,
  p/pt/pb/px/py/pl/pr=padding variants, m/mt/mb/mx/my/ml/mr=margin variants,
  maxW=maxWidth, minW=minWidth, maxH=maxHeight, minH=minHeight, rounded=borderRadius,
  z=zIndex, t=top, b=bottom, l=left, r=right, select=userSelect

Props that have NO shorthand remain as longhands:
  width, height, flex, flexDirection, flexWrap, overflow, position, fontSize,
  fontWeight, letterSpacing, lineHeight, textTransform, color, borderWidth,
  borderColor, borderBottomWidth, borderBottomColor, shadowColor, etc.

Custom tokens replaced:
- $glassBorder, $glassBackground → $borderColor, $background
- $fillDefault, $fillHigh → $green9 (accent color)
- $fillOverflow → $blue9
- $fillOverflowGlow → raw rgba(59,130,246,0.4)
- $errorBorder → $red9
- $white*, $zinc* → $color3/$color4/$color7/$color10/$color12, or raw rgba()
- $glassLid → raw rgba(255,255,255,0.15)
