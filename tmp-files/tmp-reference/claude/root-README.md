# PM Lad

Operational control system for property managers. Built by Guava AI Ltd.

**Product:** Self-service SaaS — property managers create accounts, manage properties, residents, invoices, and maintenance without engineering support.

**Stack:** NestJS + Next.js 15 + Prisma + PostgreSQL + Clerk

**Status:** Production launch in progress (Phases 1-3 complete, 4 of 7).
